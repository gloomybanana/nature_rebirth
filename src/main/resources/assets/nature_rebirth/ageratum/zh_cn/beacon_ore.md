# 信标增强矿石生成

::: tip
在岩浆与水生成石头/深板岩的位置下方放置信标，有概率生成矿石！
:::

## 机制说明

当岩浆与水相遇生成石头或深板岩时，如果在该位置下方存在信标，系统会有概率将生成的方块替换为对应的矿石。

## 默认生成概率

### 石头矿石

| 矿石类型 | 默认概率 |
|---------|---------|
| 煤矿 | 20% |
| 铁矿 | 15% |
| 红石 | 10% |
| 青金石 | 8% |
| 金矿 | 5% |
| 绿宝石 | 3% |
| 钻石 | 2% |

### 深板岩矿石

| 矿石类型 | 默认概率 |
|---------|---------|
| 深板岩煤矿 | 20% |
| 深板岩铁矿 | 15% |
| 深板岩红石 | 10% |
| 深板岩青金石 | 8% |
| 深板岩金矿 | 5% |
| 深板岩绿宝石 | 3% |
| 深板岩钻石 | 2% |

### 下界岩矿石

| 矿石类型 | 默认概率 |
|---------|---------|
| 下界石英矿 | 25% |
| 下界金矿石 | 10% |
| 远古残骸 | 1% |

## 配置选项

| 配置项 | 说明 | 默认值 |
|-------|------|--------|
| stoneOreCustomList | 石头矿石增强列表 | 见配置文件 |
| deepslateOreCustomList | 深板岩矿石增强列表 | 见配置文件 |
| netherOreCustomList | 下界矿石增强列表 | 见配置文件 |

## 自定义配置

可通过配置文件自定义矿石生成概率和类型，支持模组矿石！

::: danger
修改配置文件后需要重启游戏才能生效！
:::
