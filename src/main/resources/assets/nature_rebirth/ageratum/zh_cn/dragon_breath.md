# 龙息相关功能

本模组为龙息添加了新的合成方式和用途。

## 龙息合成

::: tip
龙首在合成过程中不会被消耗，可以重复使用！
:::

**合成方式：**
- 材料：龙首 + 玻璃瓶
- 结果：龙息

## 末地石转换

手持龙息右键以下方块可转换为末地石版本：

| 原方块 | 转换后 |
|-------|--------|
| 石头 | 末地石 |
| 圆石 | 末地石 |
| 石砖 | 末地石砖 |
| 石砖台阶 | 末地石砖台阶 |
| 石砖楼梯 | 末地石砖楼梯 |
| 石砖墙 | 末地石砖墙 |

## 配置项

| 配置项 | 说明 | 默认值 |
|-------|------|--------|
| dragonBreathCrafting | 启用龙息合成 | true |
| endStoneConversion | 启用末地石转换 | true |
