# 远古残骸转化基岩机制

::: info
在 4 级信标周围放置远古残骸，经过一段时间后会转化为基岩并掉落！
:::

## 结构布局

<structure id="nature_rebirth:structure/ancient_debris_conversion.snbt"/>

## 转化条件

- **信标等级**：必须达到 4 级信标
- **放置范围**：远古残骸需放置在信标周围水平相邻 8 格范围内
- **可同时放置多个远古残骸**

## 转化过程

1. 建造 4 级信标（金字塔底座）
2. 在信标周围水平相邻 8 格范围内放置远古残骸
3. 等待配置的延迟时间
4. 远古残骸转化为基岩
5. 基岩被破坏，以物品形式掉落

## 配置选项

| 配置项 | 说明 | 默认值 |
|-------|------|--------|
| ancientDebrisToBedrock | 启用远古残骸转化功能 | true |
| ancientDebrisConversionDelay | 转化延迟时间（秒） | 10 |

::: tip
转化延迟时间可在配置文件中调整，范围为 1-60 秒！
:::

::: warning
确保远古残骸放置在正确的范围内，否则无法触发转化！
:::
