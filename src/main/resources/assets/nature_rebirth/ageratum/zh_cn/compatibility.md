# 模组兼容

本模组支持与其他模组的兼容，自动检测并添加相应的功能。

## Craton 模组

### 添加的规则

| 底部方块 | 生成方块 | 相邻方块 |
|---------|---------|------|
| 闪长岩 | 流纹岩 | 蓝冰 |
| 凝灰岩 | 片麻岩 | 蓝冰 |
| 石英块 | 大理岩 | 蓝冰 |
| 黏土 | 辉长岩 | 蓝冰 |
| 砂砾 | 伟晶岩 | 蓝冰 |

## Mekanism 模组

### 添加的矿石生成

**石头版本：**

- 氟矿石 
- 锡矿石
- 铀矿石
- 铅矿石
- 锇矿石

**深板岩版本：**
- 深板岩氟矿石
- 深板岩锡矿石
- 深板岩铀矿石
- 深板岩铅矿石
- 深板岩锇矿石
