# 特殊岩石生成机制

本模组增强了岩浆与水的交互效果，以及岩浆流动时的特殊转化机制。

## 深板岩生成

### 机制说明

当岩浆与水相遇时，根据 Y 坐标的不同，会生成不同的方块：

- **Y >= 0**：生成普通石头
- **Y < 0**：生成深板岩

### 配置项

| 配置项 | 说明 | 默认值 |
|-------|------|--------|
| deepslateYThreshold | 深板岩生成 Y 阈值 | 0 |

## 方解石生成

::: tip
将岩浆倒在骨块上方，在岩浆旁边放置闪长岩，岩浆会转化为方解石！
:::

**图例：**
- 🔍 玻璃板 (可视化底座)
- 🟫 骨块 (底部方块)
- 🔴 岩浆 (流动到骨块上方)
- 🟪 闪长岩 (触发条件，岩浆旁边)
- ⬜ 方解石 (转化结果)

## 凝灰岩生成

::: tip
将岩浆倒在安山岩上方，在岩浆周围放置蓝冰，岩浆会转化为凝灰岩！
:::

**图例：**
- 🟫 安山岩 (底部方块)
- 🔵 蓝冰 (相邻条件)
- ⚪ 岩浆 → 凝灰石 (转化结果)

## 滴水石生成

::: tip
将岩浆倒在花岗岩上方，在岩浆周围放置蓝冰，岩浆会转化为滴水石！
:::

**图例：**
- 🟫 花岗岩 (底部方块)
- 🔵 蓝冰 (相邻条件)
- ⚪ 岩浆 → 滴水石方块 (转化结果)

## 下界岩生成

::: warning
下界岩生成需要岩浆周围同时存在蓝冰和岩浆块！
:::

**图例：**
- 🔵 蓝冰 (相邻条件)
- 🟠 岩浆块 (相邻条件)
- ⚪ 岩浆 → 下界岩 (转化结果)

## 自定义生成规则

本模组支持自定义岩浆转化规则！

**格式：** `bottom_block->generate_block:adjacent_block1,adjacent_block2`

**示例：**
- `obsidian->end_stone:soul_sand` - 岩浆在黑曜石上方且相邻灵魂沙时生成末地石
- `diorite->craton:rhyolite:blue_ice` - 支持模组方块

::: danger
修改配置文件后需要重启游戏才能生效！
:::
