# 鸡蛋捕捉机制

::: warning
向生命值为 1 的生物投掷鸡蛋，会击杀该生物并掉落对应的刷怪蛋！
:::

## 机制详情

### 成功率计算

| 生命值 | 成功率 |
|-------|--------|
| 1 | 100% |
| 2 | 90% |
| 3 | 80% |
| 4 | 70% |
| 5 | 60% |
| ... | ... |

**计算公式：** 成功率 = max(0, 100% - (生命值 - 1) × 10%)

### 使用方法

1. 将生物的生命值控制在10以下
3. 向生物投掷鸡蛋
4. 如果成功，生物会被击杀并掉落刷怪蛋

## 配置项

| 配置项 | 说明 | 默认值 |
|-------|------|--------|
| eggSpawnEgg | 启用鸡蛋捕捉机制 | true |
