# Dragon Breath Features

This mod adds new crafting methods and uses for dragon breath.

## Dragon Breath Crafting

::: tip
The dragon head is not consumed during crafting and can be reused!
:::

**Crafting:**
- Materials: Dragon Head + Glass Bottle
- Result: Dragon Breath

## End Stone Conversion

Right-click the following blocks with dragon breath to convert them to end stone variants:

| Original Block | Converted To |
|----------------|--------------|
| Stone | End Stone |
| Cobblestone | End Stone Cobblestone |
| Stone Bricks | End Stone Bricks |
| Granite | End Stone Granite |
| Diorite | End Stone Diorite |
| Andesite | End Stone Andesite |

## Configuration

| Option | Description | Default |
|--------|-------------|---------|
| dragonBreathCrafting | Enable dragon breath crafting | true |
| endStoneConversion | Enable end stone conversion | true |
