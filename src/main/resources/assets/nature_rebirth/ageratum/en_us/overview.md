# Feature Overview

Nature Rebirth is a mod designed for Minecraft that enhances natural generation mechanisms, providing players with more interesting gameplay and challenges.

## Main Features

### 🌋 Lava and Water Interaction
- Deepslate generation (Y < 0 when lava meets water)
- Beacon enhanced ore generation (generates rare ores under specific conditions)

### 🪨 Special Rock Generation
- Calcite generation (bone block + blue ice + lava)
- Tuff generation (andesite + blue ice + lava)
- Dripstone generation (granite + blue ice + lava)
- Netherrack generation (blue ice + magma block + lava)

### 💎 Ancient Debris Conversion
- Place ancient debris near a level 4 beacon
- After some time, it converts to bedrock and drops

### 🐉 Dragon Breath Features
- Dragon head crafts dragon breath
- Dragon breath converts end stone series blocks

### 🪸 Coral Mechanism
- Bone meal generates coral (requires conduit power)
- Coral revival mechanism

### 🥚 Egg Capture
- Throwing eggs at low-health mobs yields spawn eggs

## Mod Features

- ✅ Full configuration support
- ✅ JEI integration
- ✅ Multi-language support (Chinese/English)
- ✅ Mod compatibility (Craton, Mekanism)
- ✅ High-performance caching mechanism
