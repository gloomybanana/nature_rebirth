# Mod Compatibility

This mod supports compatibility with other mods, automatically detecting and adding corresponding features.

## Craton Mod

### Added Rules

| Bottom Block | Generated Block | Adjacent Block |
|--------------|-----------------|----------------|
| Diorite | Rhyolite | Blue Ice |
| Tuff | Gneiss | Blue Ice |
| Quartz Block | Marble | Blue Ice |
| Clay | Gabbro | Blue Ice |
| Gravel | Pegmatite | Blue Ice |

## Mekanism Mod

### Added Ore Generation

**Stone Versions:**

- Fluorite Ore
- Tin Ore
- Uranium Ore
- Lead Ore
- Osmium Ore

**Deepslate Versions:**

- Deepslate Fluorite Ore
- Deepslate Tin Ore
- Deepslate Uranium Ore
- Deepslate Lead Ore
- Deepslate Osmium Ore

## JEI Integration

When compatible mods are detected, obtain descriptions are added to JEI for compatible items.
