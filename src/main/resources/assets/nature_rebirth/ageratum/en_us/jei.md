# JEI Support

This mod fully supports JEI (Just Enough Items). You can view how to obtain all items in JEI.

## Viewable Obtain Methods

### Basic Items

- Bedrock obtain method
- End Stone obtain method
- Dragon Breath obtain method

### Ore Obtaining

- Various ores obtained through beacon enhancement
- Stone version ores
- Deepslate version ores

### Mod Compatibility Items

When the following mods are detected, corresponding obtain descriptions are added:

- **Craton**: Rhyolite, Gneiss, Marble, Gabbro, Pegmatite
- **Mekanism**: Fluorite Ore, Tin Ore, Uranium Ore, Lead Ore, Osmium Ore

## How to Use

1. Install JEI mod
2. Install Nature Rebirth mod
3. Open JEI in-game (default key: R)
4. Search for the item you want to view
5. Hover over the item to view obtain methods

## Configuration

JEI support is enabled by default, no additional configuration required.
